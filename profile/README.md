## 🔭 Om Oss

**NorthWeb** er et ingeniørfellesskap som fokuserer på å bygge høyytelses webapplikasjoner, pålitelige backend-tjenester og ren utvikler-rettet verktøy. Vi prioriterer effektivitet, typesikkerhet, lavlatens-arkitektur og intuitive brukeropplevelser.

---

## 🛠️ Teknologistakk

Prosjektene våre spenner over hele den moderne programvareutviklingssyklusen:

| Lag | Teknologier & Verktøy |
| :--- | :--- |
| **Frontend** | TypeScript, React, Next.js, Tailwind CSS, Vite |
| **Backend & API-er** | Go, Node.js, Python, REST & GraphQL |
| **Infrastruktur & Drift** | Docker, Linux, CI/CD-pipeliner, Cloudflare |
| **Data & Lagring** | PostgreSQL, Redis, SQLite |
